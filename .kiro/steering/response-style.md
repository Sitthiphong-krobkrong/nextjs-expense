# Response Style

เมื่อแก้โค้ดเสร็จแล้ว ให้สรุปผลลัพธ์ในรูปแบบนี้เสมอ:

## รูปแบบการตอบหลังแก้โค้ด

สรุปเป็นตาราง:

| # | รายการ | ก่อนแก้ | หลังแก้ | ดียังไง |
|---|--------|---------|---------|---------|
| 1 | ชื่อสิ่งที่แก้ | อธิบายสั้นๆ ว่าเดิมเป็นยังไง | อธิบายสั้นๆ ว่าเปลี่ยนเป็นอะไร | ผลลัพธ์ที่ผู้ใช้ได้รับ |

## Commit Message

ท้ายสุดให้แนะนำ commit message ที่พร้อมใช้งาน ในรูปแบบ:

```
<type>: <สรุปสั้นๆ>

- รายละเอียดแต่ละข้อ
```

โดย type ใช้: feat, fix, update, refactor, docs ตามความเหมาะสม
